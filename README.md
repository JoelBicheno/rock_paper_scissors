# Rock Paper Scissors

A simple Rock Paper Scissors game written in Python.

## Description

This was one of my first Python projects, created while learning Python through Mimo.

The program allows the user to:
- Choose how many rounds to play
- Play Rock Paper Scissors against the computer
- Receive feedback after each round
- See their final score
- Choose whether to play another game

## How to Run

Run `main.py` using Python.

- `random` module
